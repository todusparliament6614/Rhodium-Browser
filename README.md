## 🧭 Troubleshooting Tips

### Browser won't start
- Make sure your Windows is up to date
- Try running the installer as administrator (right-click and select "Run as administrator")
- Restart your computer and try again

### Pages load slowly
- Check your internet connection
- Clear your browsing cache (Settings > Privacy > Clear Browsing Data)
- Close unnecessary tabs to free up memory

### Downloads don't work
- Check if your firewall is blocking the browser
- Ensure you have enough storage space on your computer
- Try downloading a different file to test
